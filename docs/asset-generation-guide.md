# Asset generation guide

Everything here is optional until you generate it: the games run silently and the room stills fall back to the rendered ones when a file is missing. Nothing in this guide is downloaded or generated by the build.

## 1. Game audio (AUDIO-04)

Save every file in `client/public/audio/games/` with the exact filename shown. The code looks for these names only.

Tools: Gemini with Google Lyria for the five themes (the same route as `lore-intro.mp3`); jsfxr for the five effects (see Sound effects). After each file, add the generation date and any processing to its row in `CREDITS.md` (rows are already there, marked "pending: Gemini Lyria, generated by Boey"). Lyria output carries Google's SynthID watermark and is used under Google's generative AI terms.

Loudness and format, for every file:

- MP3, stereo, 128 to 192 kbps, 44.1 kHz. Keep each theme under about 1.5 MB.
- Themes: 60 to 90 seconds, about -16 LUFS integrated. They loop in the browser with `loop`, so make the end flow into the start: trim at a bar line, add a 0.3 s crossfade or ask Lyria for "seamless loop" and check the join by playing it twice back to back. In the game they play at half volume, so do not pre-attenuate further.
- Effects: under 1 second (the click under 0.15 s), peak about -3 dBFS, no silence at the start (trim it), no reverb tail, so they feel instant. They play at 60 percent volume.
- Style for all of them: light, 8-bit or lo-fi adjacent, instrumental, no vocals, so they sit beside the hub ambience and the lore intro.

### Sound effects

Shared by all games through `playSfx(name)`.

Main route: **jsfxr** (sfxr.me), a free browser tool that makes 8-bit effects from presets. Lyria is a music model and returns long clips, so use it only as the fallback below and cut the first note out in an audio editor. For each sound: pick the preset, adjust as noted, press play until it sounds right, then **Export .wav** and convert to MP3 (Audacity: File > Export > MP3, or `ffmpeg -i in.wav -b:a 160k out.mp3`). jsfxr sounds are yours to use; credit them in `CREDITS.md` as "made by Boey with jsfxr (sfxr.me)".

#### Correct call

- Filename: `client/public/audio/games/sfx-correct.mp3`
- Used: a verdict, case or round is right.
- jsfxr (main route): **Pickup/Coin** preset; keep it bright and short (sustain about 0.05, decay about 0.15).
- Lyria fallback prompt: A short bright 8-bit confirmation chime, two rising notes (major third), clean and friendly, under 0.5 seconds, no reverb tail. Instrumental, 8-bit, matching the hub's light chiptune feel.

#### Wrong call

- Filename: `client/public/audio/games/sfx-wrong.mp3`
- Used: a verdict, case or round is wrong.
- jsfxr (main route): **Hit/Hurt** preset, or **Blip/Select** with a negative frequency slide so it falls; lower the start frequency so it sounds soft, not harsh.
- Lyria fallback prompt: A short soft 8-bit error buzz, two falling notes (minor second), gentle not harsh, under 0.5 seconds, no reverb tail. Instrumental, 8-bit, matching the hub's light chiptune feel.

#### Win

- Filename: `client/public/audio/games/sfx-win.mp3`
- Used: a run, call or climb ends well.
- jsfxr (main route): **Powerup** preset; raise sustain so the whole thing lasts about 1 second.
- Lyria fallback prompt: A short 8-bit victory jingle, a rising major arpeggio ending on a held bright note, cheerful, about 1 second, no reverb tail. Instrumental, 8-bit, matching the hub's light chiptune feel.

#### Lose

- Filename: `client/public/audio/games/sfx-lose.mp3`
- Used: a run ends badly (phishing: too many mistakes; social: call not resisted).
- jsfxr (main route): **Powerup** preset with the frequency slide made negative so it falls, and a lower start frequency; about 1 second.
- Lyria fallback prompt: A short 8-bit defeat sting, a slow descending minor phrase ending on a low note, about 1 second, no reverb tail. Instrumental, 8-bit, matching the hub's light chiptune feel.

#### Click

- Filename: `client/public/audio/games/sfx-click.mp3`
- Used: reserved for game buttons; available to any game that adds one-line `playSfx('click')` calls.
- jsfxr (main route): **Blip/Select** preset; shorten sustain and decay until it is under 0.1 seconds.
- Lyria fallback prompt: A tiny crisp 8-bit UI tick, a single very short high blip, under 0.15 seconds. Instrumental, 8-bit, matching the hub's light chiptune feel.

### Checking

1. Run the client (`pnpm dev`), sign in and open a game. Pressing the Sound button in the room's top right should start and stop the theme.
2. Mute, then reload the tab: the theme must stay silent until you press Sound again. Closing the tab forgets the mute.
3. Play a round: the effect should match the call, and nothing should play while muted.
4. If a file is bad or absent, the game stays silent and the Sound button disappears for that room; no console error comes from the app.

## 2. Optional: AI-generated interior stills

The five game rooms already have acceptable stills rendered from the project's own Babylon scenes (`client/public/interiors/<id>.webp`, regenerated with `scripts/capture-interiors.mjs`). Replacing them with generated images is an optional upgrade, not required for the games to work. Keep the rendered ones unless a generated image is clearly better and matches the hub.

Tool: ChatGPT image generation or Gemini image generation. Shared style block, prepend it to every room prompt:

> Stylised low-poly 3D diorama of a small Victorian-era room, warm toon shading, soft rounded shapes, gentle ambient occlusion, slightly elevated three-quarter camera looking into the room, 16:9 landscape, 1880s Thames wharf mood, matching a cosy game-hub look. No text or lettering except the signs listed for this room, no real-world logos or brands, no people other than the characters listed, no watermark. Keep the centre and lower middle of the frame quiet and uncluttered (a game panel covers it); put the detail around the left, right and top edges.

Output for each: export 1600 x 900 WebP (quality about 80, keep it near 30 to 60 KB if you can) and save it as `client/public/interiors/<id>.webp`, replacing the rendered still. The 2D mode, no-WebGL and slow-device cases show this file (`InteriorLayout.vue` uses it behind the desk panel with a slight blur, so keep the centre uncluttered). The desk panel covers the lower-middle, so put detail around the edges.

### Recording sources

After using a generated image or audio file, edit `CREDITS.md`:

- For a still: change the `client/public/interiors/*.webp` row, or add a row per file, naming the tool and model, the date, "AI-generated by Boey from a text prompt (no reference images)", and any processing (crop, resize to 1600 x 900, WebP quality).
- For audio: replace "pending: Gemini Lyria, generated by Boey" with the same detail (tool, date, prompt used, processing such as trim, loop join, loudness, final bitrate).
- Keep the prompt text in the row or in `.local-handover/` so the file can be regenerated. Do not add third-party images or music without a licence entry.
